# Lesson 8

Я зробив 3 завдання:

1. Створив таблиці для книг, авторів, категорій в БД

2. Написав код на Go що читає дані з PostgreSQL через GORM

3. Перевіряв проблему N+1 - коли програма робить окремі запити для пов'язаних даних кожного запису.

Додав JOIN для категорій, але перевірку N+1 ще потрібно завершити. Старі скріншоти не показують кількість запитів для одного звернення.

Код які змінив:
- internal/repository/book_gorm.go - запит для списку книг
- internal/model/book.go - додав теги для зв'язків
- migrations/000001_init_schema.up.sql - таблиці БД
